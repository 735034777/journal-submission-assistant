## 作者指南要求 G

| 项目 | 要求 | 指南章节 |
|---|---|---|
| 主稿 | 可编辑源文件，Word 单栏；PDF 不代替源文件 | File format |
| 标题页 | 作者顺序与系统一致，单位及通讯邮箱完整 | Title page |
| 摘要 | 最多 250 词 | Abstract |
| 关键词 | 英文 1–7 个 | Keywords |
| Highlights | 必需、独立可编辑文件，文件名含 highlights；3–5 条，每条最多 85 字符含空格 | Highlights |
| 图文摘要 | 鼓励提供，不设为必需 | Graphical abstract |
| 利益冲突 | 声明工具生成 Word 文件用于上传 | Declaration of competing interests |
| 贡献 | CRediT | Author contributions: CRediT |
| 数据 | 可用性声明，存储/引用/链接数据；不能共享时解释 | Research data / Data statement |
| 审稿形式 | 单匿名，不自动删除作者信息 | Peer review |

依据：[作者指南](https://www.sciencedirect.com/journal/applied-energy/publish/guide-for-authors)。指南列研究、综述、技术评估、观点等类型，实际下拉标签待登录核对。伦理、AI、版权与作者同意按当前稿件逐项处理。

## 文档证据 D 与未验证 U

- D：官方注册截图有邮箱、名、姓、密码、保持登录、邮件偏好、条款；不是用真实邮箱打开的 APEN 后续表单。
- L：APEN 注册表的字段和必填星号已观察，见[注册表实测](applied-energy-registration.md)；提交端校验和后续页面仍待验证。
- D：官方新版指南描述投稿流程；APEN 当前作者、基金、附加问题和校验 U。
- L：用户授权邮箱已实际提交，进入已有账号分支；一次性链接邮件已请求。此通用实例不记录个人邮箱。
- L：期刊账号可用及资料保存已从注册后的页面核实；最终确认点击过程未被工具观察。
- U：新建 Elsevier 统一账号、期刊注册完成邮件、上传、稿件草稿保存与最终投稿仍未验证。

已有账号身份和期刊资料表已核查，后续填写按用户确认的真实资料进行。新账号分支另需用户确实希望注册、尚未注册的邮箱及本人资料；不能使用虚假地址或资料。可交付本地整理功能，但不宣传为通过端到端实测。

## 执行经验

识别当前域名和行为，按钮名不保证传统流程。机构提示不等于个人登录；关闭整个登录窗与切换个人方式是不同动作。iframe 加载会刷新控件，先获取新状态。

[本地规则文件](applied-energy.rules.json)只支持有限预检查。每次操作前核查官网数字，记录变化。
