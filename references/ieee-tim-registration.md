# IEEE TIM：独立账号注册实测

观察日期：2026-09-11。目标为 IEEE Transactions on Instrumentation and Measurement（TIM），只验证本次实际分支，不代表全部 IEEE 期刊。

## 入口与身份

- [官方作者指南](https://ieee-ims.org/publication/ieee-tim/information-authors)指向 [PeerTrack／Editorial Manager](https://www.editorialmanager.com/tim/)。当前登录页提供独立用户名密码及 ORCID，未见 Elsevier 统一身份入口。
- 登录页有多个刊物选项，操作前核对当前刊物。相同邮箱已能登录其他出版社的 EM 系统，不证明可登录本期刊。
- Register → Pre-registration Page，必填名、姓、邮箱；可以导入 ORCID，也明确允许不使用 ORCID 继续。当前提交后进入完整注册表，未出现重复记录提示；这不等于账号已创建。

## 完整注册表

| 字段 | 当前观察及处理 |
|---|---|
| Preferred user name | 必填；需在系统内唯一，最终是否可用以页面校验为准 |
| Password / Re-type Password | 均必填；按工具要求由用户创建、输入、确认及提交，不保存到作者 YAML 或日志 |
| Title / Given name / Family name / Email | 必填；作者资料按当前可编辑字段回读 |
| Telephone Number | 必填；页面要求包括国家代码 |
| Position | 必填；不能由称谓或学位推断职位 |
| Institution | 必填；有机构联想候选 |
| Street Address / City / Zip or Postal Code / Country or Region | 必填；不能把仅有城市、院校或邮编的资料自行补成完整街道地址 |
| Available as a Reviewer | 必填；按用户明确偏好填写 |
| Personal Classifications | 必填，主表和分类窗口均提示至少 3 项 |
| Degree / ORCID / Department / Personal Keywords | 当前未标必填；稿件提交阶段的要求需另查 |

模板按当前必填字段补充，用户名与账号状态另记；密码和验证码不进入文件。只有普通资料准备完成后再交接新密码操作，用户接管期间不要并行修改同一表单。

## 分类匹配与阶段差异

分类窗口可展开、勾选、Add，再 Submit 保存。实测两项明确匹配加入已选列表后，Submit 仍禁用；补充第三项有依据的分类后启用。点击 Submit 后已在主注册表回读三项正式名称，验证了分类回填，但账号尚未创建。点击分类文字行可能仅滚动定位，需核对实际复选框及已选列表。

依据[分类匹配机制](classification-matching.md)匹配正式候选。有明确同义项时自动选入；方向无可靠对应时询问作者，不用院系、相关领域或重复父级凑足数量。未达到数量要求、保存按钮禁用时，仅报告已选待保存，不能称为保存成功。

作者指南的稿件提交说明要求两项 EDICS，与本次账号个人分类至少三项属于不同阶段，不能互相覆盖。指南中的作者 ORCID 要求也不能倒推为当前预注册必须绑定 ORCID。

## 本轮验证范围

已观察官方入口、独立账号预注册、完整字段、分类候选与数量校验。普通必填资料已填写并核对，三项有依据的分类已回填主表，其中一项采用已向作者说明的较宽概念；无可靠对应的原始方向保留为未匹配，没有改选相邻领域。当前等待用户输入并提交新登录凭据；最终注册、验证邮件、账号可登录状态和稿件提交均未验证。实际进度与个人值保存在任务记录中，不进入通用技能包。
